# Renaldi — Personal Portfolio (v2)

Personal portfolio web application engineered with **Next.js 14 (App Router)**, **TypeScript**, and **Tailwind CSS**, designed following the **Frontend Craft & Anti-Slop** design principles.

---

## ✨ Features & Architecture

- **High-Standard Craft**: Built according to Linear/Vercel-level aesthetic standards — no generic AI-slop gradients, zero emojis in headings/labels, subtle 1px neutral borders, crisp typography hierarchy, and purposeful micro-interactions (`active:scale-[0.98]`, `focus-visible:ring-2`).
- **Typography & Metrics**: Scaled with `Geist` & `Geist Mono` with `tabular-nums` for all stats, numbers, and counts.
- **Dark & Light Mode**: Fluid theme switching with persistence via `next-themes`.
- **Selected Works & Filtering**: Dynamic category filters (`All · 4`, `Web`, `Mobile`, `Landing Page`), featuring prominent hero showcase and 3-column project cards.
- **Interactive Capabilities**:
  - Figma-inspired design canvas with mobile preview, inspector panel, and collaborator cursor.
  - Interactive multi-tab code window with syntax highlighting and one-click copy.
  - Mobile app product showcase with subtle ambient glow.
- **Tech Stack Breakdown**: Visual distribution bar across 5 layers (Backend, Frontend, Database, DevOps, Design) with interactive highlights.
- **Tactile Contact**: One-click email copy with instant visual feedback and direct communication channels (WhatsApp, Email, Instagram).
